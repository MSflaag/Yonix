AVERTISSEMENT & INTRODUCTION :
Ce guide complet vous donne les techniques avancées pour contourner les bannissements 
de serveurs Discord et obtenir le débannissement de comptes désactivés par Discord Trust & Safety.

--------------------------------------------------------------------------------
PARTIE 1 : CONTOURNER UN BAN DE SERVEUR DISCORD (IP & MATÉRIEL)
--------------------------------------------------------------------------------
Lorsqu'un modérateur ou administrateur vous bannit d'un serveur Discord :
- Votre compte est banni.
- Votre adresse IP publique est bannie.
- Vos cookies et votre identifiant client sont blacklistés pour ce serveur.

Si vous recréez un compte sur le même PC sans suivre cette méthode, le nouveau compte 
sera automatiquement banni à la seconde où vous cliquez sur l'invitation !

MÉTHODE DE RECONNEXION PROPRE :
1. Fermez complètement Discord (clic droit dans la barre des tâches > Quitter Discord).
2. Nettoyez les données et traces locales Discord :
   - Appuyez sur [Touche Windows] + [R].
   - Tapez `%appdata%` et supprimez le dossier "discord".
   - Tapez `%localappdata%` et supprimez le dossier "Discord".
3. Changer d'adresse IP (OBLIGATOIRE) :
   - Option 1 (Recommandée) : Partagez la connexion 4G/5G de votre smartphone avec votre PC. 
     (Les IP mobiles changent à chaque activation du mode avion et ne sont jamais blacklistées).
   - Option 2 : Redémarrez votre box internet pour obtenir une nouvelle adresse IP dynamique.
   - Option 3 : Utilisez un VPN de qualité (Mullvad, ProtonVPN, NordVPN).
4. Création du compte :
   - Utilisez un profil de navigateur vierge ou une fenêtre de navigation privée.
   - Créez un nouveau compte avec une adresse email valide (Gmail, Outlook ou Proton).
   - N'associez PAS le même numéro de téléphone que votre compte banni !
5. Rejoignez le serveur : vous pouvez désormais rejoindre le serveur sans aucun blocage.

--------------------------------------------------------------------------------
PARTIE 2 : DÉBANNISSEMENT DE COMPTE DISCORD SUSPENDU (TRUST & SAFETY)
--------------------------------------------------------------------------------
Si Discord a désactivé votre compte pour violation des Conditions d'utilisation (ToS) :

ÉTAPE 1 — SOUMETTRE LE TICKET OFFICIEL :
1. Rendez-vous sur le formulaire officiel : https://dis.gd/request
2. Dans le menu déroulant, sélectionnez :
   "Appeals & age update requests" (Contestations et demandes de mise à jour d'âge)
3. Sélectionnez le sous-motif exact correspondant à votre situation :
   - "Appeal an action taken on my account" (Contester une action sur mon compte)
   ou
   - "My account was compromised" (Mon compte a été piraté)

PARTIE 4 : CONSEILS D'EXPERTS POUR LA RÉSOLUTION
--------------------------------------------------------------------------------
1. Ne relancez PAS votre ticket toutes les 24h : cela réinitialise votre position dans la file d'attente.
2. Répondez calmement à l'email automatique initial pour confirmer que votre problème persiste.
3. Le délai de réponse varie généralement de 48 heures à 7 jours ouvrés.
